# Nour Modern Lighting: B2B website (MVP preview)

Bilingual (Arabic RTL default / English) B2B site for Nour Modern Lighting, an Egyptian electrical panel manufacturer.
This MVP is a **static Next.js site with no backend**, built to show the customer the direction quickly. The full platform (database, admin, secure uploads, CRM) is specified in `../Site.md`.

## What works
- Home, Products (search, category, height filter, sort, mobile filter drawer), product detail (gallery, specs, related products, JSON-LD), About, Industries, Contact (map)
- **Quotation basket** (localStorage): quantity, standard/custom and notes per item
- **Request form** with 4 paths: selected products, BOQ upload, custom manufacturing, general project. Validated with Zod and issues a reference number `NR-YYMMDD-XXXX`. The request is sent to sales via a **pre-filled WhatsApp message or email** (no server yet). Files are validated and listed, and the user attaches them in WhatsApp/email.
- No prices, no "Buy now". Real products and photos come from Nour's existing catalog.

## Architecture (plain language)
- `app/[lang]/…`: pages. `/` redirects to `/ar`. All 131 pages are pre-rendered at build time.
- `messages/ar.ts`, `messages/en.ts`: every piece of UI text, reviewable by a human (no machine translation).
- `data/products.json`, `data/categories.json`: product data generated by `scripts/import-catalog.mjs` from the old catalog export in `scripts/source/`. See `scripts/import-report.md`.
- `lib/basket.ts`: quotation basket store. `lib/quote.ts`: validation and reference numbers. `lib/site.ts`: contact details.
- `components/`: header, footer, product card/browser/gallery, quote form.

## Commands
```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build (type-checks)
npm run lint
node scripts/import-catalog.mjs --dry-run   # re-import product data
```

## Deploy
`npx vercel` (preview) or `npx vercel --prod`. No environment variables are needed for the MVP.
